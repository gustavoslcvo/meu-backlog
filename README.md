# Meu Backlog

Fiz esse projeto para organizar ideias de sistemas e coisas que quero estudar. É um site bem simples onde você anota a atividade, a linguagem que vai usar e deixa algumas observações guardadas.

Usei as seguintes tecnologias:
- HTML, CSS e JavaScript.
- **Firebase** (cuidando do banco de dados para salvar as ideias e do sistema de login).
